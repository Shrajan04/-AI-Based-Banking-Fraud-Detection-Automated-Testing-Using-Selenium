AI-Based Banking Fraud Detection & Automated Testing Using Selenium

This is a simulated online banking system built as a software testing college project. Every money transfer is checked by a rule-based fraud detection engine which gives a risk score (0-100), a risk level (LOW / MEDIUM / HIGH) and the reasons for the score.

  • LOW (0-29) - transaction approved
  • MEDIUM (30-59) - approved with a warning, fraud alert created
  • HIGH (60-100) - transaction blocked, fraud alert created
